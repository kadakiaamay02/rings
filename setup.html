One-time setup

Turn on saving for the ring pages

Saving writes each ring's spec into your rings repo on GitHub. That needs a GitHub key. Paste the key here once with the password you want. The page locks the key with the password and stores the locked copy in the repo. After that, the password is all anyone needs to save.

  1. Open GitHub → New fine-grained token.
  2. Under Repository access, choose Only select repositories and pick rings.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as it is.
  4. Generate the token, copy it, and paste it below.

The token stays in this browser until it is locked, and it is only ever sent to GitHub. When the token expires, saves will say so. Make a new token and run this page again.
